4. Add tests following [Testing Guides](testing/)

#### Deploying
1. Review [Deployment Guide](deployment/DEPLOYMENT_GUIDE.md)
2. Follow [Deployment Best Practices](deployment/DEPLOYMENT_BEST_PRACTICES.md)

1. See [Debug Guide](guides/DEBUG_GUIDE.md)
2. Check relevant feature documentation
3. Review implementation history if needed

## 📝 Documentation Standards

### For Contributors
- Use clear, descriptive titles
- Include table of contents for long documents
- Add "Last Updated" dates
- Link to related documentation
- Keep documentation up-to-date with code changes

### For AI Agents
- Always read `PROJECT_CONTEXT.md` first
- Check `.cursorrules` for coding standards
- Review relevant feature docs before making changes
- Update documentation when adding features
