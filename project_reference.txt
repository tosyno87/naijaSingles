# NaijaSingles Project Reference Guide

## Project Overview
NaijaSingles is a Flutter-based mobile dating application created for singles in Nigeria. The app lets users discover matches, chat, and meet new people nearby. It integrates Firebase, location services, and in-app purchases to provide a complete social experience.

## Tech Stack
- Flutter 3.32.3 with Dart 3.5
- Firebase (Auth, Firestore, Storage, Messaging)
- Google Maps API
- BLoC pattern for state management
- Provider for simpler state management
- In-App Purchases

## Project Structure

### Main Directories
- `/lib` - Main source code
  - `/common` - Shared utilities, constants, and widgets
  - `/features` - Feature-based modules
  - `/models` - Data models
  - `/services` - Service classes

## Firebase Structure

### Authentication
- Email/Password
- Phone Authentication
- Google Sign-In
- Facebook Sign-In

### Firestore Collections
- `users` - User profiles
  - `likes` - Subcollection of user likes
  - `dislikes` - Subcollection of user dislikes
- `matches` - Match records between users
- `chatThreads` - Chat conversation metadata
- `messages` - Individual chat messages
- `notifications` - User notifications

### Storage
- `profile_images` - User profile photos
- `chat_media` - Images and files shared in chats

## Common Issues and Solutions

### Location Services
- Location permission handling in `/lib/features/user/ui/screens/allow_location.dart`
- Distance calculation in `/lib/common/utils/distance.dart`

### Authentication Flow
- Auth state persistence handled in `/lib/common/providers/user_provider.dart`
- Social login logic in respective BLoC files

### Image Handling
- Image compression in `/lib/common/utils/image_utils.dart`
- Upload logic in `/lib/services/storage_service.dart`
